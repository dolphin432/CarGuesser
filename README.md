# CarGuesser
A hypercar and supersportcar guessing game.Guess the car by its engine price country year and horsepower.Features Normal Hint and Expert modes.
CarGuesser is a hypercar guessing game.

Guess the mystery car by comparing engine, price, country, year and horsepower.

Features:
- Normal Mode
- Hint Mode
- Expert Mode

Requirements:
- Python 3.13 or higher (python.org)
- tkinter (included with Python)

How to play:
1. Download all 4 files: car_game.py, cars.json, stats.json, settings.json
2. Put all files in the same folder
3. Run car_game.py with Python

Note: All 4 files must be in the same folder!
